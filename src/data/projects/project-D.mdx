# Introduction

Project AeroDeliver aims to automate the delivery process using drones equipped with advanced navigation and object detection systems. It reduces delivery times and operational costs.

## Key Features

- **Autonomous Navigation**: Drones use GPS and computer vision for precise navigation.
- **Obstacle Avoidance**: Real-time object detection to avoid collisions.
- **Package Tracking**: Live tracking of deliveries through a mobile app.
- **Fleet Management**: Centralized control for managing multiple drones.

## Technical Insights

- **Embedded Systems**: Programmed drone controllers using C++ and ROS for real-time operations.
- **Computer Vision**: Used OpenCV for object detection and obstacle avoidance.
- **Cloud Integration**: Leveraged AWS IoT for communication between drones and the control center.
- **Mobile App**: Developed a companion app for users to track deliveries and provide feedback.

## Challenges and Solutions

- **Navigation Accuracy**: Integrated GPS with computer vision to improve navigation in urban areas. Tall buildings degraded GPS signal, so visual landmarks and sensor fusion corrected the position estimate when satellite data was unreliable.
- **Battery Life**: Optimized flight paths to conserve energy and extend battery life. Route planning accounted for payload weight, wind, and altitude changes, and drones returned to charge with a safety margin rather than at the limit.
- **Regulatory Compliance**: Ensured compliance with local aviation regulations for drone operations. Geofencing, flight logging, and altitude limits were built into the software, and test flights were planned with the required approvals.
- **Real-Time Constraints**: Obstacle avoidance had to react within milliseconds on limited onboard hardware. Running the vision pipeline at a reduced resolution and using lightweight detection models kept latency low enough for safe flight.
- **Connectivity Loss**: Drones could drop their cloud connection mid-flight. Onboard autonomy allowed them to finish or safely abort a delivery and return home, syncing logs once reconnected.
- **Weather Conditions**: Wind and rain affected stability and sensor quality. Conservative weather thresholds, wind-compensated control, and automatic grounding in poor conditions protected both drones and packages.
- **Safe Package Handover**: Releasing a package safely in a busy area proved harder than flying. A controlled descent, a clear landing-zone check, and a tether-based drop mechanism reduced risk to people nearby.
- **Simulation Before Flight**: Testing on real drones was slow and risky. Using ROS simulation to validate navigation and failure scenarios before field tests saved time and prevented costly crashes.

> ❗ **Safety first**: Every new behavior was validated in simulation before it was ever flown, and failures defaulted to returning home.

## Outcome

Project AeroDeliver successfully completed pilot tests in a suburban area, demonstrating its potential to transform last-mile delivery. It received interest from logistics companies for further development.

- **Operational Savings**: Automating the delivery route cut out much of the manual coordination, pointing to meaningful reductions in delivery time and operating cost.
- **Safety Record**: Layered obstacle avoidance, geofencing, and fail-safe return-to-home behavior meant the pilot ran without safety incidents.
- **Technical Validation**: The pilot showed that combining GPS with computer vision can navigate reliably in environments where GPS alone is inaccurate.
- **Cross-Disciplinary Teamwork**: Working with six people across hardware, embedded software, vision, and cloud gave me valuable experience integrating very different systems under real-world constraints.
- **Future Directions**: Next steps include longer-range batteries, weather-aware route planning, and swarm coordination to serve multiple deliveries at once.
